GITHUB SUBMISSION GUIDE

    WHEN WILL IT APPEAR IN THE GAME?

    Submit an Issue on GitHub. The system creates a PR for review. Once the maintainer merges it, the change automatically syncs to the game when it next loads the updated map list. You do not need to update AAE.

    WHAT IS A PR (PULL REQUEST)?

    A PR (Pull Request) is a proposed change for the maintainer to review. You submit an Issue; the system creates the PR automatically. Only merged PRs become official.
